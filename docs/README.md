# Rollcall docs

- `ideas/`: use cases, one short file each. Start from [`_template.md`](ideas/_template.md).
- `features/`: the feature list and its status.
- `implementations/`: how each feature is built.

## Add an idea
1. Copy `ideas/_template.md` to `ideas/NNN-name.md`.
2. Fill it in. Keep it to one screen.
3. Add a line to [`features/README.md`](features/README.md).

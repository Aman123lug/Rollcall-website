# 008 · Voice macros

**Status:** Idea · **Updated:** 2026-09-25

**In one line:** save a set of steps with a name, then say the name to run them again.

## Problem
The same multi-step edits (intro, outro, lower third) get rebuilt by hand every time.

## How it works
1. After an edit, say "save that as my outro".
2. Later, say "outro" at any point to run the same steps there.
3. Macros are listed and editable.

## First version
- Save from the last few commands.
- Run at the playhead.

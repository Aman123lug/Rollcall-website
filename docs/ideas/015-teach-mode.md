# 015 · Teach mode

**Status:** Idea · **Updated:** 2026-09-25

**In one line:** "show me how to do that manually": Rollcall replays the menu path so beginners learn the editor.

## Problem
Beginners use Rollcall but never learn the editor underneath.

## How it works
1. After any voice edit, say "show me how".
2. Rollcall highlights each menu and click it would take, step by step.
3. Optional: practise mode, where you do it and Rollcall checks.

## First version
- Replay the menu path for common edits in one editor.

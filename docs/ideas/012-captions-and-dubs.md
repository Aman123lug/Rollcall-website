# 012 · Captions and dubs in other languages

**Status:** Idea · **Updated:** 2026-09-25

**In one line:** one sentence makes translated captions (and later dubbed audio) for each platform version.

## Problem
Reaching other languages means separate caption files and edits per version.

## How it works
1. Say "add Spanish and Hindi captions".
2. Rollcall translates the transcript and styles captions to match.
3. Each language gets its own caption track and export version.

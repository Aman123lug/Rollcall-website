# 007 · Edit like me

**Status:** Idea · **Updated:** 2026-09-25

**In one line:** Rollcall learns your usual style, so "do my usual" just works.

## Problem
Creators repeat the same caption style, grade, pacing and intro on every video.

## How it works
1. Rollcall learns from past projects (with permission): captions, grade, cut pace, music level, intro.
2. Say "do my usual" or "captions like last time".
3. Style is saved as a profile you can view and edit.

## First version
- Caption style and grade learned from the last few projects.
- One editable style profile.

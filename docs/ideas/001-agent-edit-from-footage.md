# 001 · Agent edit from your footage

**Status:** Idea · **Updated:** 2026-09-25

**In one line:** pick a video; Rollcall watches it, suggests an edit style, and builds the first cut in layers you refine by voice.

## Problem
With raw footage, the hardest part is deciding what the edit should be. Then comes an hour of layering music, sound effects and captions by hand.

## How it works
1. **Select** a clip or the current timeline.
2. **Say what you want**, or just "what can you do with this?"
3. **Rollcall reads the video** and summarises it: what happens, the mood, the best moments.
4. **It suggests 2–3 styles** that fit, e.g. comedy short, vlog, travel, cinematic recap.
5. **The agent builds the edit** as separate tracks: cuts, music, sound effects, ambience, captions, titles.
6. **Refine** by voice (agent mode) or edit the tracks by hand (manual mode). Every change can be undone.

## First version
- One clip in.
- 3 styles: vlog, comedy short, travel.
- Layers: cuts, music, captions, sound effects.
- One editor.

## Rules
- Video is analysed on the Mac. Only a text summary (timestamps, transcript, tags) goes to the model.
- Every layer is a normal, labelled track the user can mute or delete.

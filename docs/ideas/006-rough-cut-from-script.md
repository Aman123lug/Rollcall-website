# 006 · Rough cut from a script

**Status:** Idea · **Updated:** 2026-09-25

**In one line:** paste the script and Rollcall assembles the cut from the best take of each line.

## Problem
Syncing takes to a script and picking the best one is slow, repetitive work.

## How it works
1. Paste or import the script.
2. Rollcall matches each line to the takes that say it.
3. It picks the best take (no flubs, restarts or long pauses) and builds the rough cut.
4. Swap any take by voice: "use the second take for line 4".

## First version
- Talking-head and interview footage.
- Flub and restart detection.

# 014 · Hardware push-to-talk

**Status:** Idea · **Updated:** 2026-09-25

**In one line:** hold a Stream Deck key, foot pedal or AirPods squeeze to talk, with both hands on the timeline.

## Problem
Reaching for a keyboard shortcut breaks the editing flow.

## How it works
1. Pair a device in settings.
2. Hold to talk, release to send.
3. Optional: map device buttons to macros.

## First version
- Stream Deck and a keyboard key.
- Foot pedals later.

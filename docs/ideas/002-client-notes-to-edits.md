# 002 · Client notes → edits

**Status:** Idea · **Updated:** 2026-09-25

**In one line:** paste client feedback and Rollcall turns each note into an edit, applies it, and ticks it off.

## Problem
Revision rounds are slow: reading notes, finding each timecode, making the change, then reporting back.

## How it works
1. Paste notes, or import timecoded comments (Frame.io, PDF, email).
2. Rollcall turns each note into an edit plan at its timecode.
3. Review the plan, then apply all or one by one.
4. Each note is marked done, with a changelog to send back to the client.

## First version
- Pasted text and Frame.io comments.
- Cuts, captions, audio levels, text changes.
- Changelog export.

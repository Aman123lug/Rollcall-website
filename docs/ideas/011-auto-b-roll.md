# 011 · Auto B-roll

**Status:** Idea · **Updated:** 2026-09-25

**In one line:** lay B-roll from your own library over narration, matched to what's being said.

## Problem
Finding and placing B-roll for every mention is slow.

## How it works
1. Rollcall indexes your media library on the Mac.
2. It matches narration keywords to clips ("…then we got to the beach" → beach clips).
3. B-roll lands on its own track; swap any clip by voice.

## First version
- Keyword matching against clip tags.
- Own library only.

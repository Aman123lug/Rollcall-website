# 013 · Accessibility: voice-first editing

**Status:** Idea · **Updated:** 2026-09-25

**In one line:** a full editing workflow for people who can't, or shouldn't, use a mouse all day.

## Problem
RSI and limited mobility make long mouse-heavy edit sessions painful or impossible.

## How it works
1. Every common action is reachable by voice.
2. Navigation by voice: "next cut", "back five seconds", "select the title".
3. Clear spoken or visual confirmation for each action.

## First version
- Voice navigation and selection.
- Custom wake word or push-to-talk key.

## Open questions
- Talk to editors with RSI and disabilities early.
- Screen-reader support for Rollcall's own UI?
